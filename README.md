# PDF Orbit 360 🌐📄

An all-in-one PDF processing, conversion, and document intelligence platform.

## ✨ Features Roadmap
- **Merge & Split**: Seamlessly combine or extract PDF pages.
- **Convert**: Convert between PDF, Images, Word, Excel, and Text.
- **Compress**: High-efficiency compression without quality loss.
- **Rotate & Organize**: Rotate, reorder, and delete pages visually.
- **OCR & Text Extraction**: Extract searchable text from scanned PDFs.
- **Protect & Unlock**: Secure documents with passwords and permissions.

## 🚀 Getting Started

### Prerequisites
- Modern web browser or Node.js runtime.

### Development Setup
Clone the repository:
```bash
git clone https://github.com/justdineshsingh1-jpg/pdf-orbit-360.git
cd pdf-orbit-360
```
